THE OUTPUT ISN'T A SCREENSHOT.

The system produces structured application knowledge. A semantic specification of what the app is and how it works.

Screens
Array<ScreenNode>
Stable identities for every discovered visual state.
Elements
Array<UIElement>
Semantic roles, bounds, actions, and content descriptions.
Forms
Map<FormState>
Linked input fields, submission buttons, and validation rules.
Transitions
GraphEdges
Directional mappings of how actions lead from one screen to another.
Journeys
Array<FlowSequence>
Identified end-to-end user flows like login, checkout, or KYC.
Design Tokens
StyleObject
Extracted color palettes, typography scales, and spacing units.
