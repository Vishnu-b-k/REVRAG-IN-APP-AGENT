# RevRag Viewer

Interactive viewer for RevRag Knowledge Packs generated by the autonomous app exploration system.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The viewer will open at [http://localhost:3000](http://localhost:3000).

## Build

```bash
# Production build
npm run build

# Preview production build
npm run preview
```

## Features

### Screen Profile (M-0 + M-1)
- Screen name, ID, fingerprint
- Purpose description
- Screenshot with fallback
- Semantic elements with role, label, bounds, and actions
- Forms with resolved field labels, submit button, and validation rules
- Metadata grid with element/form/transition counts

### App Map (M-1)
- Visual node-link diagram of all discovered screens
- SVG edges showing transitions between screens
- Layered BFS layout from entry screen
- Click any node to navigate to its screen profile
- Active screen highlighting

### Transitions (M-1)
- Outgoing and incoming transitions for each screen
- Action type and label for each transition
- Clickable destination screens for navigation

### Journeys (M-1)
- User flow visualization with step chips
- Current screen highlighted in journey context
- Clickable journey steps for cross-navigation

### Design Tokens (M-1)
- Per-screen color swatches with roles
- Typography, spacing, and mode properties
- Global Design System section with color palettes, typography hierarchy, and spacing system

### View Modes (M-1)
Toggle between **Screen Profile** and **App Map** via sidebar buttons.

## Network Independence

The viewer works entirely offline. All data is bundled at build time:

- Knowledge Pack is imported as a JSON module
- Screenshots are served from `public/screenshots/`
- No backend API calls are made
- File upload allows loading a real pack without a backend

## Deployment

**Platform**: [Vercel](https://vercel.com)
**Public URL**: https://viewer-beige-one.vercel.app

### Deploy / Redeploy

```bash
# From the viewer/ directory:
vercel deploy --prod --yes
```

### Configuration

- **Build command**: `npm run build`
- **Output directory**: `dist`
- **Install command**: `npm ci`
- **Framework**: Vite
- **Environment variables**: None required

Configuration is in [`vercel.json`](vercel.json).

### Reproducing from scratch

```bash
cd viewer
npm install -g vercel    # one-time
vercel login             # one-time
vercel deploy --prod --yes
```

## Architecture Notes

- **Data Loader** (`data-loader.js`): Isolated module for loading and validating the Knowledge Pack. Supports bundled mock pack (default) and file upload for real packs. Includes a normalization layer that handles structural differences in real packs.
- **Rendering**: All UI is dynamically generated from the pack data. No screen is hardcoded.
- **Styling**: Pure CSS with custom properties (design tokens). No CSS framework.
- **No framework**: Vanilla JS with Vite as bundler. Zero runtime dependencies.
